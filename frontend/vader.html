Om mätningarna

Temperaturerna kommer från SMHI:s öppna API för meteorologiska observationer (parameter 1 — lufttemperatur, senaste timmen). Nätet omfattar drygt 200 automatiska stationer, från Falsterbo i söder till Karesuando i norr.

Alla mätningar görs 1,5–2 meter över marken i ventilerade strålningsskydd enligt WMO:s standard. Kvalitetsflaggan G (grön) betyder kontrollerat värde; preliminära värden kan justeras i efterhand.

Stationer som inte rapporterat den senaste timmen visas inte på kartan — därför varierar antalet punkter något från timme till timme.

Vanliga frågor

Hur ofta uppdateras kartan?

SMHI publicerar timvisa observationer och Sverige Nu hämtar dem var 15:e minut. Tidsstämpeln i varje stations-tooltip visar exakt mättidpunkt.

Varför saknas min ort?

Kartan visar SMHI:s automatiska mätstationer — inte varje ort. Hovra över närmaste punkt; temperaturen stämmer oftast väl inom någon mil, utom i fjällterräng.

Vad betyder höjdangivelsen?

Stationens höjd över havet. Temperaturen sjunker i snitt ~0,65°C per 100 meter, så fjällstationer mäter ofta flera grader kallare än dalgångarna intill.

Kommer fler väderdata?

Ja — nederbörd, vind, snödjup och lufttryck finns i samma API och står på tur att läggas till.
